# Resona 🎵

![Resona UI](./public/assets/SS-1.png) ![Authentication](./public/assets/SS-2.png)

Resona is a **full-stack web-based music application** where users can enjoy a curated collection of songs.  
It now includes **user authentication** (Signup, Login, and Logout) with **credentials securely stored in MongoDB**, powered by **Node.js, Express, and EJS** for server-side rendering.

---

## 🚀 Features

- 🎧 Play songs directly from the interface  
- 👤 **User Authentication**  
  - Signup, Login, and Logout functionality  
  - Credentials securely stored in MongoDB  
- ⚙️ **Backend Integration** using Node.js & Express  
- 🖥️ **Server-Side Rendering** with EJS templates   
- 🧭 Well-structured project setup combining frontend and backend

---

## 🔮 Future Enhancements

- Fully **responsive** and mobile-friendly layout  
- **Dynamic song loading** from an API

## 💻 Getting Started

Follow these steps to clone and run the project locally:

```bash
git clone https://github.com/Pranjl7/Resona.git
cd Resona
npm install
npm start

```
